The new constructor observer exposed a real engine-owned orphan, rather than
a test-only count difference. Godot 4.3 initialization discards the prior
physical connection handle without closing it; the wrapper must close first.
The dated engine fact belongs beside the existing transport-tooling fact.
The faulted eight-player host also created a cyclic global-confirmation wait
while future submissions were needed to refresh receipt gossip. Endpoint-receipt
pacing preserves the independent final acceptance checks. These repairs pass
final source-bound browser verification on both engine pins.

The final receipt also rejected legitimate Godot 4.7.2 import outputs: 47 new
UID sidecars and a rewritten pinned SDK icon import file. The import boundary
now rejects changed authored bytes and unpaired new files, then freezes all
post-import metadata through export and execution. Mutation controls protect
this boundary; the final bound receipt passes and preserves all authored bytes.
